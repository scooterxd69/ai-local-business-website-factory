The AI Local Business Website Factory is an open-source engine that takes a structured JSON record of a real local business — restaurant, salon, or coaching institute — and produces a complete, mobile-responsive, XSS-safe static website. No frameworks. No JavaScript on the page. Just honest HTML and CSS.

How it works

The pipeline is small and the boundaries are sharp.

  1. 1

    Structured input

    A Business record (Zod-validated) describes what the business actually is: name, location, hours, services, contact, brand colour. No marketing copy is invented by the system.

  2. 2

    Category profile

    Each category — restaurant, salon, coaching — picks a default order of section types and a default theme. The profile is data, not code branches.

  3. 3

    Validate the spec

    The composed WebsiteSpec is itself Zod-validated. Hero must come first. Footer appears once. At least one content section. The renderer fails fast on bad input.

  4. 4

    Render — safely

    The renderer emits a single HTML file and a single CSS file. Every text node goes through escape(). Every URL goes through sanitizeUrl() and escapeUrl(). The output is XSS-safe by construction.

What ships in Milestone 1

Deliberately small. The renderer is the foundation; everything else is on top.

  • Renderer

    Pure function renderWebsite(spec, business) returning {html, css, structuredData, assets}. 14 section types. Mobile-first CSS with theme variables.

  • Schemas

    Zod-validated Business and WebsiteSpec as the single source of truth. TypeScript types are inferred from the schemas.

  • Security boundary

    HTML, URL, and JSON escape helpers. sanitizeUrl rejects javascript:, data:, file:, and vbscript:. 26 security tests pin the contract.

  • Category profiles

    3 profiles (restaurant, salon, coaching). Each one chooses a section order and a default theme. Sections without underlying data are omitted — never invented.

  • CLI

    npm run render -- --business file.json --out dist/. Renders to index.html, styles.css, structured-data.json.

  • Tests

    69 tests across 6 files. Schemas, renderer, security, samples. Runs in ~1.5s.

What does not ship yet

Milestone 1 proves the engine. The product layer comes next.

  • No AI generation

    Sample inputs are hand-authored JSON. Calling Claude to produce a Business record is Milestone 2.

  • No web UI

    There is no onboarding form, no live editor, no preview pane. Those are the next layer once the engine is proven.

  • No database

    Each render is a pure function of its inputs. Persistence is intentionally not in scope yet.

  • No hosting tier

    Generated sites are static. The customer hosts them. Subdomain-as-a-service is on the roadmap.
